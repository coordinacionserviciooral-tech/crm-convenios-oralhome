# CRM Oralhome

Aplicación de convenios con acceso por roles, tarifas anuales, seguimientos, exportación, archivado, restauración, auditoría y alertas desde Supabase.

```powershell
npm ci
# Crear .env.local a partir de .env.example
npm run dev
npm run check
```

La base de datos existente es la fuente de información; nunca se reemplaza automáticamente con un CSV. Ver `GUIA_INSTALACION.md` para publicación, recuperación de contraseña, permisos y programación de alertas.
